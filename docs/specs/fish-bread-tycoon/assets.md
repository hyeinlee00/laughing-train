# 붕어빵 장인 — 비주얼 리소스 스펙

게임 동작 계약은 [spec.md](./spec.md)를 따른다. 이 문서는 그 게임을 표현하는
이미지 리소스를 제작할 때만 참고하는 별도 컨텍스트다.

분위기 목표: 2000년대 한국 피처폰 게임의 복고 감성 + 현대적인 웹 게임 UI.
기존 게임의 그래픽·캐릭터·에셋을 복제하지 않고, 전체 리소스의 스타일을
일관되게 유지한다. 4시간 개발 제한 안에서 리소스를 과도하게 만들지 않고,
핵심 게임 플레이가 잘 보이는 것을 장식보다 우선한다. 가능하면 SVG 또는
투명 배경 PNG를 우선한다.

## 직접 제작 vs CSS/JS 처리

**직접 제작하는 리소스** (게임의 개성을 결정하므로):

1. 붕어빵 (상태별 이미지)
2. 손님 캐릭터
3. 불꽃/연기 등 조리 관련 핵심 그래픽

**이미지로 만들지 않고 CSS/JS로 구현하는 것**: 버튼, 패널, 타이머, 굽기
게이지, 콤보 표시, 점수 팝업, PERFECT 텍스트, 화면 흔들림, 확대/축소 효과,
파티클, 반짝임, 진행 바, 말풍선, 그림자 등 대부분의 UI 장식.

**외부 무료 리소스를 검색해서 쓰는 것**: 배경, 일부 장식용 소품.

## 붕어빵 리소스

게임에서 가장 중요한 핵심 그래픽. 귀엽고 맛있어 보이면서도 작은 크기에서
상태 변화가 명확히 구분되어야 한다.

**스타일**: 2D, 레트로 게임 느낌, 약간의 픽셀아트 감성(너무 복잡한 픽셀아트는
피함), 현대 웹 게임에서도 어색하지 않은 깔끔한 형태, 따뜻하고 맛있는 느낌,
작은 화면에서도 잘 보이는 외곽선, 투명 배경, 모든 상태가 동일한 카메라
각도·비율을 유지.

**필요한 상태** (하나의 디자인 기준 4가지 — `EMPTY`는 이미지 불필요):

- `BATTER` — 반죽이 들어간 상태: 밝은 반죽 색, 아직 형태가 완전히 선명하지
  않음, 부드럽고 말랑한 느낌.
- `COOKING` — 굽는 중: 점점 노릇해지는 과정, 약간의 증기, 완성품보다 밝은 색.
- `READY` — 완성: 황금빛 갈색, 표면 디테일이 잘 보임, 바삭하고 가장
  먹음직스러운 상태.
- `BURNT` — 탄 상태: 어두운 갈색~검은색, 탄 부분, 약간의 연기, 한눈에 실패를
  알아볼 수 있어야 함.

`FLIPPED` 상태가 필요하면 기존 디자인을 크게 바꾸지 않고 뒤집힌 느낌만
표현한다.

**파일 구조** (가능하면):

```text
assets/bungeoppang/batter.svg (또는 .png)
assets/bungeoppang/cooking.svg
assets/bungeoppang/ready.svg
assets/bungeoppang/burnt.svg
```

모든 이미지는 캔버스 크기와 중심점을 동일하게 유지한다.

## 손님 캐릭터

손님은 주인공이 아니라 주문과 시간 압박을 전달하는 역할이므로 디테일을
과도하게 만들지 않는다.

**스타일**: 붕어빵과 동일한 2D 레트로 스타일, 귀엽고 약간 코믹함, 상반신 또는
전신, 투명 배경, 작은 화면에서도 얼굴·실루엣이 구분되어야 함.

**필요한 캐릭터**: 4명 정도 (예: 직장인, 학생, 어르신, 아이). 캐릭터마다
색상과 실루엣을 확실히 다르게 한다.

**표정**: 가능하면 캐릭터당 기본/기다림/만족/화남 중 2~3개. 시간이 부족하면
캐릭터당 기본 이미지 1개만 만들고 표정 변화는 CSS/JS나 텍스트로 처리한다.

**파일 구조**:

```text
assets/customers/customer_01.svg (또는 .png)
assets/customers/customer_02.svg
assets/customers/customer_03.svg
assets/customers/customer_04.svg
```

## 불꽃 / 조리 효과 리소스

붕어빵을 굽고 있다는 느낌을 강화한다. 정적인 하나의 이미지보다는 몇 개의
프레임을 조합하거나 CSS 애니메이션하기 좋은 형태로 제작한다.

**필요한 리소스**: 작은 불꽃, 큰 불꽃, 연기, 증기, 작은 불씨/파티클.

**스타일**: 붕어빵과 동일한 레트로 2D 스타일, 작은 크기에서도 명확한
실루엣, 투명 배경, 너무 사실적인 불꽃은 피함.

**파일 구조**:

```text
assets/effects/fire_small.svg (또는 .png)
assets/effects/fire_large.svg
assets/effects/smoke.svg
assets/effects/steam.svg
```

여러 장의 파티클 이미지를 만들기보다 1~2개의 기본 이미지를 CSS/JS로
반복·회전·확대해서 사용한다.

## CSS/JS로 구현할 피드백 효과 (이미지로 만들지 않음)

- **굽기 게이지**: 막대 또는 원형 게이지, 조리 상태에 따라 색상·크기 변화.
- **PERFECT/GOOD 효과**: 텍스트가 작게 나타난 뒤 빠르게 확대되며 위로 이동해
  사라짐 (`PERFECT! +500`, `GOOD! +300`). GOOD은 PERFECT보다 작은 애니메이션.
- **BURNT 효과**: 짧은 화면 흔들림 + 연기 효과 (`💨 BURNED!`).
- **COMBO**: 살짝 작게 시작 → 빠르게 확대 → 원래 크기로 복귀 (`🔥 COMBO x5`).
- **점수 팝업**: 발생 위치에서 위로 떠오르며 사라짐.
- **화면 흔들림**: 붕어빵이 탐 / 높은 콤보 달성 / 보너스 획득 / 게임 종료
  시에만 짧게, 너무 강하지 않게.
- **틀 클릭 피드백**: 살짝 눌리는 효과 + 약간의 scale down + 빠른 원상복귀.

## 배경 리소스

직접 제작하지 않고 무료 에셋을 먼저 검색한다. 목표 분위기: 밤의 한국
길거리 포장마차 / 붕어빵 노점 / 따뜻한 겨울 분위기 / 레트로 게임.

**검색 키워드 예시** (영어 검색 결과가 더 풍부함): `pixel art Korean street
food stall`, `pixel art food cart`, `pixel art night market`, `pixel art
winter street`, `retro pixel art street food`, `pixel art cooking shop
background`.

**추천 검색처**: Kenney, OpenGameArt, itch.io Game Assets, 기타 라이선스가
명확한 무료 게임 에셋 사이트.

**라이선스 우선순위**: 1) CC0, 2) 상업적 사용 가능 + 수정 가능 라이선스,
3) 사용 조건이 명확히 확인되는 기타 무료 에셋. 라이선스가 불명확한 이미지는
쓰지 않는다. 특히 출처 불명 이미지, 다른 게임의 스크린샷/배경 추출본,
캐릭터·브랜드·IP가 포함된 이미지는 피한다.

**배경 선택 기준**: 중앙에 UI를 올릴 빈 공간이 있고, 너무 복잡하지 않고,
어두운 영역이 있어 흰 텍스트가 잘 보이고, 붕어빵 틀과 명확히 구분되고,
가로형 화면에 적합해야 한다. 디테일이 너무 많거나 캐릭터가 크게 그려져
있거나 UI와 색이 겹치는 배경은 피한다.

배경 자체를 수정하기보다 CSS 오버레이(반투명 어두운 그라디언트)로 UI 가독성을
확보한다.

## 완료 확인 체크리스트

- [ ] 붕어빵 상태별 이미지의 크기가 동일한가?
- [ ] 붕어빵 상태가 한눈에 구분되는가?
- [ ] 손님과 붕어빵의 스타일이 일관적인가?
- [ ] 투명 배경이 정상적으로 적용됐는가?
- [ ] 불꽃/연기 리소스가 작은 크기에서도 보이는가?
- [ ] 배경이 게임 UI를 방해하지 않는가?
- [ ] 모든 외부 에셋의 라이선스를 확인했는가?
- [ ] 불필요하게 많은 이미지를 만들지 않았는가?

## 가장 중요한 원칙

리소스의 개수보다 게임의 손맛이 중요하다. 붕어빵이 잘 보이고 굽는 타이밍이
잘 보이고 눌렀을 때 PERFECT/COMBO 피드백이 잘 움직이면 충분하다. 시간은
게임 플레이 → 피드백 → 애니메이션 → UI 폴리싱 순서로 투자하고, 리소스
제작에 과도한 시간을 쓰지 않는다.
