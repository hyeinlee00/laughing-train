# 05 — 60초 타이머와 난이도 곡선

## Outcome

게임은 시작부터 정확히 60초 동안 진행된다. 0~20초/20~40초/40~60초 구간마다
조리 시간, 주문 수량, 손님 등장 속도가 스펙에 정의된 대로 단계적으로
빡빡해진다. 60초가 끝나면 모든 조작이 즉시 막히고 결과 화면으로 전환할
준비 상태가 된다.

## Blockers

- 02-cooking-state-flow — 시간 구간에 따라 조정되는 조리 시간 파라미터가
  존재해야 한다.
- 03-customer-orders-and-sales — 시간 구간에 따라 조정되는 주문 수량과
  손님 등장 속도 파라미터가 존재해야 한다.

## Acceptance criteria

- [ ] 게임 시작 시 60부터 카운트다운을 시작한다.
- [ ] 0~20초 구간에서는 스펙에 정의된 여유 있는 조리 시간과 1~2개 주문
      수량이 적용된다.
- [ ] 20~40초 구간에서는 조리 시간이 짧아지고 주문 수량 2~3개, 손님 등장
      속도가 빨라진다.
- [ ] 40~60초 구간에서는 조리 시간이 더 짧아지고 주문 수량 2~4개가
      적용된다.
- [ ] 남은 시간이 0이 되는 즉시 모든 틀 조작과 판매 동작이 비활성화된다.
- [ ] 시간 종료 시 결과 화면으로의 전환이 트리거된다.

## Constraints

None.

## Verification

- 자동 테스트: 경과 시간 값을 입력으로 각 구간(0~20/20~40/40~60초)에서
  반환되는 조리 시간/주문 수량/손님 등장 속도 파라미터가 스펙과 일치하는지
  검증.
- 자동 테스트(컴포넌트): 타이머가 0에 도달하면 틀 클릭/키 입력이 더 이상
  상태를 바꾸지 않는지 검증.
- 브라우저 확인: 실제로 60초를 플레이하며 후반부에 여러 틀을 동시에
  처리해야 하는 긴장감이 발생하는지 확인.
