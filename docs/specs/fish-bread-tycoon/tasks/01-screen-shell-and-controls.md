# 01 — 화면 골격과 조작

## Outcome

시작 화면에서 "게임 시작"을 누르면 게임 화면으로 전환된다. 게임 화면에는
6개의 붕어빵 틀(플레이스홀더 비주얼)이 넘버패드 물리적 배열과 동일하게
배치되고(위: 4·5·6, 아래: 1·2·3), 매출·남은시간·콤보·현재 손님 주문을 보여줄
표시 영역이 존재한다(값은 정적 플레이스홀더). 마우스 클릭과 키보드 1~6은
같은 틀을 같은 방식으로 대상 지정한다. 데스크톱과 모바일 뷰포트 모두에서
레이아웃이 깨지지 않는다.

## Blockers

None.

## Acceptance criteria

- [ ] 시작 화면에서 "게임 시작" 클릭 시 게임 화면으로 전환된다.
- [ ] 게임 화면에 6개의 틀이 위 4·5·6 / 아래 1·2·3 순서로 배치되어 보인다.
- [ ] 매출 / 남은 시간 / 콤보 / 현재 손님 주문 표시 영역이 화면에 보인다.
- [ ] 특정 틀을 마우스로 클릭한 것과 대응하는 키보드 숫자(1~6)를 누른 것이
      동일한 동작을 일으킨다.
- [ ] 데스크톱 폭과 모바일 폭(예: 375px) 모두에서 레이아웃이 겹치거나
      잘리지 않는다.

## Constraints

붕어빵 틀, 배경 등은 `assets.md`에 정의된 실제 이미지 리소스 없이 색상
블록/텍스트 라벨 등의 플레이스홀더로 표현한다 (spec.md 공유 제약).

## Verification

- 자동 테스트: 틀 컴포넌트가 넘버패드 순서(4·5·6 윗줄, 1·2·3 아랫줄)로
  렌더링되는지 검증.
- 자동 테스트: 각 틀에 대해 클릭 핸들러와 대응 키보드 입력 핸들러가 동일한
  함수/동작을 호출하는지 검증.
- 브라우저 확인: 데스크톱 및 모바일 뷰포트(next-dev-loop)에서 시작→게임
  화면 전환과 레이아웃을 육안으로 확인.
