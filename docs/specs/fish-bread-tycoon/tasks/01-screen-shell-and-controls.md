# 01 — 화면 골격과 조작

## Outcome

시작 화면에서 "게임 시작"을 누르면 게임 화면으로 전환된다. 게임 화면에는
9개의 붕어빵 틀(플레이스홀더 비주얼)이 넘버패드 물리적 배열과 동일하게
배치되고(위: 7·8·9, 가운데: 4·5·6, 아래: 1·2·3), 매출·남은시간·콤보·현재
손님 주문을 보여줄 표시 영역이 존재한다(값은 정적 플레이스홀더). 마우스
클릭과 키보드 1~9는 같은 틀을 같은 방식으로 대상 지정한다. 화면 전체는
가로:세로 9:16 비율의 세로로 긴 패널이며, 데스크톱과 모바일 뷰포트 모두에서
레이아웃이 깨지지 않는다.

블록/텍스트 라벨 등의 플레이스홀더로 표현한다 (spec.md 공유 제약).
