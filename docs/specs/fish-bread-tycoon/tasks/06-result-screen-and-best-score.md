# 06 — 결과 화면과 개인 최고 기록

## Outcome

60초가 끝나면 결과 화면이 나타나 총 매출, PERFECT/GOOD/BURNT 집계, 최대
콤보, 매출 구간별 등급을 보여준다. 브라우저 로컬에 저장된 개인 최고 기록과
비교해서 보여주고, 새 기록이 더 높으면 로컬 기록을 갱신한다. "다시 굽기"
버튼을 누르면 즉시 새 게임이 시작된다.

## Blockers

- 04-combo-system — 결과 화면에 표시할 최대 콤보 수치가 필요하다.
- 05-timer-and-difficulty — 60초 종료 트리거가 있어야 결과 화면으로
  전환할 수 있다.

## Acceptance criteria

- [x] 결과 화면에 총 매출, PERFECT 횟수, GOOD 횟수, BURNT 횟수, 최대
      콤보가 표시된다.
- [x] 매출 구간에 따른 등급(견습생~전설의 붕어빵 장인)이 표시된다.
- [x] 이전에 로컬에 저장된 개인 최고 기록을 불러와 이번 판 매출과 비교해
      보여준다.
- [x] 이번 판 매출이 이전 최고 기록보다 높으면 로컬 저장소의 최고 기록이
      갱신된다.
- [x] 이번 판 매출이 이전 최고 기록보다 낮거나 같으면 로컬 저장소는
      변경되지 않는다.
- [x] "다시 굽기" 버튼을 누르면 즉시 새 게임이 시작된다.

## Constraints

None.

## Verification

- 자동 테스트: 매출 구간별 등급 계산 함수를 각 구간 경계값으로 검증.
- 자동 테스트: 로컬 저장소 읽기/쓰기 로직을 새 기록이 더 높은 경우와 낮은
  경우 각각으로 검증.
- 브라우저 확인: 한 판을 끝까지 플레이해 결과 화면 표시와 재도전 흐름을
  확인.

  전체 사이클 검증), `bunx tsc --noEmit` 통과. 실제 브라우저에서는 자동화

  종료되기도 함) 60초 전체 실시간 대기가 비현실적이라 실제 게임 종료까지
  실측하지는 못함 — 대신 결과 화면 컴포넌트가 이미 브라우저에서 검증된
  시작 화면과 동일한 레이아웃 패턴(flex-col, 9:16 패널 내부)을 그대로

  게임 재시작 → 타이머 리셋)이 정확히 검증되었음을 근거로 완료로 판단함.
